`train_7k.ply` is `FO_dataset/train/point_cloud/iteration_7000/point_cloud.ply` from the Hugging Face dataset [Voxel51/gaussian_splatting](https://huggingface.co/datasets/Voxel51/gaussian_splatting), whose card is tagged Apache-2.0. The reconstruction was produced with the reference 3D Gaussian Splatting implementation by Inria / MPII (Kerbl et al., 2023), whose released models are intended for research and evaluation. The underlying images come from the Tanks and Temples benchmark. Treat this file as research/non-commercial sample data and do not ship it with a product.

Regenerate the synthetic samples with:

```sh
python tools/splatgen/gen_test_splats.py
```

All files are standard binary 3DGS PLY in the COLMAP convention (Y down). The editor's splat import applies a 180 degree rotation about X so they appear upright. Load them with File > Import Gaussian Splat (.ply) or the Scene Hierarchy's "Import Splat..." button.
